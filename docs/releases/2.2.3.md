# POM 2.2.3 — visible, gentle support reminders

**Download `POM-2.2.3.dmg` below. Requires macOS 14+; Apple silicon and Intel.**

- A small, non-modal support window appears on the first launch and after a newer app version. It does not take keyboard focus or block POM.
- Reminders appear at most once every seven days. Relaunching, reinstalling the same version or downgrading does not repeat them. Updates skipped during the cooldown never cause a delayed reminder.
- Choose **Not now** or close the window to continue. A later eligible app update can show the reminder again.
- The usage window now has a visible **Support POM** button with text. The DMG includes a support link, and its installation guide explains voluntary support in English and Lithuanian.
- POM stays free. Stripe accepts a one-time amount chosen by the supporter (€5 suggested). No reminder timers, background network requests, payment SDK or donation tracking were added; only a few local preferences are stored.

Validation: 255 core checks, including reminder persistence, version ordering and cooldown cases; LT/EN welcome and update views in light/dark appearances; universal compilation and local package checks.

**Not Apple-notarized:** this release is ad-hoc signed, so macOS may block the first launch. The checksum and signed update feed verify integrity, not Apple approval. See [Apple's explanation](https://support.apple.com/en-us/102445). Quit POM and replace it in Applications using the DMG; the in-app update check opens this release page.

**Lietuviškai:** pirmą kartą paleidus POM ir po atnaujinimo rodomas nedidelis paramos priminimas, ne dažniau kaip kartą per 7 dienas. Jį galima užverti arba pasirinkti **Gal vėliau**. Programos apačioje matomas mygtukas **Paremti POM**, o DMG pakete pridėta paramos nuoroda. Priminimas neblokuoja darbo, visos funkcijos lieka nemokamos. Leidimas nenotarizuotas.
