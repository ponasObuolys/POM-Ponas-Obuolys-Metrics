# POM 2.2.0

Claude and Codex usage monitoring, now in English and Lithuanian.

- Follow the Mac's primary language or switch instantly in Settings.
- Show several providers together in the menu bar.
- Explore locally collected usage in interactive 7- and 30-day charts.
- Get notified when fresh data confirms an exhausted limit has recovered.
- See Claude extra usage and Codex credit balances, monthly limits and reset credits when provided.
- Check for updates and install future signed releases through Sparkle.
- Universal Apple silicon and Intel build, macOS 14 or later.

History starts as readings arrive and is stored only on this Mac for 30 days.
No usage forecasts or automatic credit purchases/redemptions.

Upgrading from 2.1.2 requires this DMG once, because the older app has no updater.
For the signing/notarization status, see the repository README. This release must
not be published until all signing and notarization checks have passed.
