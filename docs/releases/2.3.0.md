# POM 2.3.0 — Cursor, Grok Bot and Bento dashboard

Development version for macOS 14+, Apple silicon and Intel. Public release assets have not been published.

- Cursor usage limits, reset times and on-demand spend, using the existing local sign-in after explicit opt-in.
- Grok Bot weekly usage from the active account's local cache, preserving its original update time.
- A Bento dashboard that reflows selected services without scrolling. The largest card follows the highest used-limit percentage; a pin keeps one chosen service largest across launches.
- Bundled Cursor and Grok Bot icons and a readable Claude-family symbol for Fable in cards, the source picker and the menu bar.
- Separate Claude and ChatGPT sign-in actions, with an immediate usage refresh after successful sign-in. Expired timers show unknown usage until fresh readings arrive.

Validation: 332 core checks; all 31 non-empty service selections and five pinning variants; LT/EN and light/dark SwiftUI views; expired readings and failed refresh states; layout geometry checks; universal local package verification.

The local development package is ad-hoc signed and has not been Apple-notarized.
