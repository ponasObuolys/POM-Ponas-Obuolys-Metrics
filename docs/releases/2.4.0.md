# POM 2.4.0 — Dashboard, history and independent Grok refresh

Local development update for macOS 14+, Apple silicon and Intel. Public release assets have not been published.

- Apply used/remaining percentages consistently to dashboard meters and menu indicators; warning colors continue to reflect usage.
- Select dashboard and menu services independently, with migration from existing preferences and protection against hiding the last service.
- Add a 420-point compact view alongside the 744-point card layout, persistent manual order, automatic pinning, and screen-height-aware scrolling.
- Explain data status and sources, show refresh activity, and display local reset times without treating elapsed resets as confirmed recovery.
- Add completed-day averages, two completed-week comparisons, chart filters and line styles, and 7/30-day JSON or CSV exports. JSON retains report schema v1 and Companion compatibility.
- Fetch Grok Bot usage directly through the existing Cursor session when enabled. Local-summary mode remains available. Decode Cursor's macOS safeStorage envelope instead of sending encrypted text as a bearer token; distinguish local credential errors from rejected sessions.
- Update Claude, ChatGPT, Cursor and Grok Bot plan labels while preserving unfamiliar provider names. See [plan-name maintenance](../PLAN-NAMES.md).

## Validation

411 core checks and SwiftUI rendering/integration checks passed, including settings migration, provider visibility/order, history calculations, encrypted session decoding and refresh cancellation. Companion checks cover report import and selected-period exports.

A live test on 2026-11-03 used the unmodified POM refresh model and real server in a diagnostic process. With Cursor and Grok Bot closed throughout, successful Grok readings arrived at 00:42:45 and 00:47:46 Europe/Vilnius, without manual refresh or shortened timers. This verifies the refresh module; it is not an observation of the installed app's window.

See [interface details](../USAGE-INTERFACE.md) and [Cursor/Grok integration](../CURSOR-GROK-METRICS.md). Local bundles are ad-hoc signed and are not Apple-notarized. No public release or release tag is part of this update.
