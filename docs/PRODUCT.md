# Product copy

## GitHub description
Native macOS menu bar app for Claude and Codex usage limits, reset times and extra credits. Daily token history. English and Lithuanian.

## Short description
POM keeps Claude and Codex usage limits in your Mac's menu bar. See what is left,
when limits reset and which extra credits are available. Open daily token charts,
choose useful alerts and keep several providers visible at once.

## Longer description
Working between Claude Code and Codex should not require opening several settings
pages just to check your limits. POM brings their subscription usage into a small,
native macOS app. Provider logos and colored indicators make the remaining quota
visible while you work. Click for reset times, account plans and extra usage details.

POM also shows interactive 7- and 30-day token charts: local Claude Code usage and
Codex account usage, combined across models. Import is incremental and runs in
small background batches; history refreshes every 15 minutes. Notifications
can warn before a limit runs out and let you know when fresh readings confirm it
has recovered. The interface follows your Mac's language, supports English and
Lithuanian, and lets you switch manually. POM is open source and works with your
existing CLI sign-in; there is no separate API key or POM account.

Publication note: these descriptions cover 2.2. Do not announce a downloadable,
notarized 2.2 release before Apple signing and notarization have succeeded.

## Aprašymas lietuviškai
POM rodo Claude ir Codex naudojimo limitus tiesiog Mac meniu juostoje. Vienu
žvilgsniu matyk likutį, atsistatymo laiką ir papildomus kreditus. Peržiūrėk naudojimo
istoriją, pasirink pranešimus ir laikyk kelių įrankių indikatorius šalia laikrodžio.
Programa veikia lietuviškai ir angliškai, o istoriją saugo tik tavo kompiuteryje.
