POM — Claude & Codex usage limits in your Mac menu bar

English
1. Drag POM into Applications, then open it from Applications.
2. Sign in to Claude Code and/or Codex CLI. POM reads their usage automatically.
3. Click the menu bar indicators to see limits, credits and History.
4. Open Settings to select indicators, alerts, Language and automatic updates.

POM follows your Mac's language (Lithuanian or English; other languages use English).
You can switch immediately in Settings > Language. History shows 30 days of tokens: Claude Code on this Mac and Codex account usage.
The first local import runs in small background batches. No API key is required.

If macOS blocks the app, confirm that it came from the official GitHub release.
This 2.2.2 release and older releases are not Apple-notarized. Do not disable Gatekeeper.
See the current signing status and installation help in the repository README.

Lietuviškai
1. Nutempk POM į Applications aplanką ir paleisk iš jo.
2. Prisijunk prie Claude Code ir (arba) Codex CLI. POM limitus perskaitys pati.
3. Paspausk meniu juostos indikatorius: matysi limitus, kreditus ir istoriją.
4. Nustatymuose pasirink indikatorius, pranešimus, kalbą ir naujinimus.

POM parenka kompiuterio kalbą. Ją galima iš karto pakeisti nustatymuose.
Istorija rodo 30 dienų tokenus: Claude Code šiame Mac ir Codex paskyros naudojimą.
Pirmas vietinių įrašų importas vyksta mažomis porcijomis fone.
API rakto nereikia.

Jei macOS blokuoja programą, patikrink, ar ji gauta iš oficialaus GitHub leidimo.
Šis 2.2.2 leidimas ir ankstesni leidimai Apple nenotarizuoti. Neišjunk Gatekeeper apsaugos.
